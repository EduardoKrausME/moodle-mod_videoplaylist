# Video Playlist (`mod_videoplaylist`)

Moodle activity module containing multiple trackable videos in one activity.

Features:

- Multiple videos per activity.
- Upload, direct URL/HLS, YouTube and Vimeo sources.
- Per-video watched-segment tracking, resume position and percentage.
- Optional sequential unlocking based on each video's minimum percentage.
- Overall progress calculated as the arithmetic mean of enabled videos.
- Custom completion rule based on overall percentage.
- Gradebook integration using overall percentage.
- Teacher management page and per-student/per-video report.
- Backup/restore and Privacy API support.

Designed for Moodle 4.5+.
